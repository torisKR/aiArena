EN / Privacy Policy

Tokenfront: Orbital Signal War

Summary

The App is provided by Toris. This release has no account system, cloud sync, advertising SDK, analytics SDK, crash-reporting SDK, purchase SDK, or server endpoint.

Information stored on your device

Game progress and settings stay on your device. This may include War Token balance, cosmetics, language, accessibility, camera, haptics, audio, local privacy choices, Signal Chronicle progress, medals, transmissions, endings, and directive-bonus history. Android automatic cloud backup is disabled, and release rules exclude local state from cloud backup and device-to-device transfer. Android users can clear App data or uninstall; web users can clear the site’s local storage.

Analytics and advertising choices

Consent settings are stored locally so players retain control if related features are introduced later. This release sends them nowhere. Gameplay and performance events may be held temporarily in memory during a session, but are not transmitted and are discarded when the App process ends.

Data collection and sharing

  • Personal data collected off device: none
  • Data shared with third parties: none
  • Accounts or cloud profiles: none
  • Location, contacts, photos, camera, or microphone access: none
  • Advertising identifiers: none

Retention and deletion

Toris retains no App data on a server because this release sends no data off device. Clear the App’s storage or uninstall it to remove local progress and settings.

Public policy hosting

The complete policy is also readable in the App. Opening this Cloudflare Pages URL is an explicit external-browser action. Cloudflare Pages and the external browser may process ordinary web-request data, such as IP address and routing data, under their own terms. The Android App does not embed this page or send gameplay or local-state data to it.

Children’s privacy

The App is intended for players aged 13 and older and is not directed to children under 13. This release does not collect personal information. If a future release changes these practices, this policy and relevant store disclosures will be updated before publication.

Security

Keeping data on your device and omitting network collection reduces exposure. No storage method is completely secure, so keep your device and operating system protected.

Changes

The effective date will be revised when features or legal requirements materially change.

KO / 개인정보처리방침

Tokenfront: 궤도 신호전

요약

앱은 Toris가 제공하는 오프라인 게임입니다. 이 릴리스에는 계정, 클라우드 동기화, 광고 SDK, 분석 SDK, 오류 보고 SDK, 결제 SDK 및 서버 통신 엔드포인트가 없으며 개인정보를 수집·전송·판매하거나 제3자와 공유하지 않습니다.

기기에 저장되는 정보

게임 진행 상태와 설정만 사용자의 기기에 저장됩니다. War Token 잔액, 꾸미기 항목, 언어, 접근성, 카메라, 햅틱, 오디오, 로컬 개인정보 선택, Signal Chronicle 진행, 메달, 전송 기록, 엔딩 및 지령 보너스 기록이 포함될 수 있습니다. Android 자동 클라우드 백업은 비활성화되어 있으며 릴리스 규칙은 로컬 상태를 클라우드 백업과 기기 간 전송에서 제외합니다. Android에서는 앱 데이터 삭제 또는 제거로, 웹에서는 사이트 로컬 저장소 삭제로 지울 수 있습니다.

분석 및 광고 선택

향후 관련 기능이 도입될 경우에도 이용자가 선택권을 갖도록 동의 설정이 포함되어 있습니다. 이 릴리스에서 선택값은 기기에만 저장됩니다. 게임플레이 및 성능 이벤트가 세션 중 메모리에 일시 보관될 수 있으나 외부로 전송되지 않고 앱 프로세스 종료 시 삭제됩니다.

데이터 수집 및 공유

  • 기기 외부로 수집하는 개인정보: 없음
  • 제3자와 공유하는 데이터: 없음
  • 계정 또는 클라우드 프로필: 없음
  • 위치, 연락처, 사진, 카메라 또는 마이크 접근: 없음
  • 광고 식별자: 없음

보유 및 삭제

이 릴리스는 데이터를 기기 외부로 전송하지 않으므로 Toris가 서버에 보유하는 앱 데이터가 없습니다. 앱 저장공간을 삭제하거나 앱을 제거하면 로컬 진행 상태와 설정이 삭제됩니다.

공개 정책 페이지 호스팅

전체 방침은 앱에서도 읽을 수 있습니다. 이 Cloudflare Pages URL을 여는 것은 외부 브라우저에서 명시적으로 수행하는 동작입니다. Cloudflare Pages와 외부 브라우저는 자체 조건에 따라 IP 주소와 라우팅 정보 등 일반적인 웹 요청 데이터를 처리할 수 있습니다. Android 앱은 이 페이지를 내장하지 않으며 게임플레이나 로컬 상태 데이터를 보내지 않습니다.

아동의 개인정보

앱은 만 13세 이상 이용자를 대상으로 하며 만 13세 미만 아동을 대상으로 하지 않습니다. 이 릴리스는 개인정보를 수집하지 않습니다. 향후 릴리스에서 처리 방식이 바뀌는 경우 공개 전에 이 방침과 관련 스토어 정보를 업데이트합니다.

보안

정보를 기기에만 보관하고 네트워크 수집을 하지 않아 노출 가능성을 줄입니다. 다만 어떠한 저장 방식도 완전한 보안을 보장하지 않으므로 기기와 운영체제를 안전하게 유지해 주세요.
