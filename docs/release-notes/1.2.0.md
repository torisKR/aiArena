# Tokenfront 1.2.0 release notes

Paste the per-locale block into the matching Play Console "What's new" field.
Play limits each locale to 500 characters; counts below are verified.

The uploaded versionCode is generated by CI (Unix seconds), not by
`pubspec.yaml`. Only the version name 1.2.0 comes from the manifest.

## ko-KR (425 chars)

```
엔딩 이후에도 계속 플레이할 수 있는 에코 주기가 추가됐습니다.

[에코 주기]
• 결말을 본 뒤에도 다섯 작전이 다시 열립니다. 정사 기록(메달·전송·결말)은 그대로 보존됩니다.
• 주기가 오를수록 제한 시간이 짧아집니다(90초 → 78초 → 66초 → 54초). 회수 시간은 그대로입니다.
• 반대 결말을 기록하면 CHECKSUM SCAR, 첫 에코 주기를 클리어하면 ECHO ORBIT을 얻습니다.
• 아카이브에서 작전별 최선 회수 시간을 확인할 수 있습니다.

[전투 화면]
• 목적지 조작부를 좌우 측면으로 옮겨 가려졌던 노드와 본진이 모두 보입니다.
• 폴더블 접힘선에 목적지 버튼이 걸리지 않습니다.

[조작감]
• 노드 회수 시간을 10초에서 8초로 줄였습니다.
• 회수 중 진행 정도가 노드에 원형으로 표시되고, 절반 지점에 눈금이 생깁니다.
```

## en-US

```
Echo Cycle lets the campaign continue after an ending.

[Echo Cycle]
• All five operations reopen. Medals and your ending stay intact.
• Each cycle tightens the clock: 90s, 78s, 66s, 54s.
• Unlock CHECKSUM SCAR and ECHO ORBIT.
• The archive tracks your best time per operation.

[Battle screen]
• Destination controls moved to side rails, so hidden nodes and your base show.
• No button sits on the hinge.

[Feel]
• Node recovery cut to 8s.
• Nodes show an occupancy arc with a halfway notch.
```

## ja-JP

```
エンディング後も遊び続けられるエコーサイクルを追加しました。

[エコーサイクル]
• 結末を迎えた後も5つの作戦が再び開きます。正史の記録（メダル・通信・結末）はそのまま保存されます。
• サイクルが進むほど制限時間が短くなります（90秒→78秒→66秒→54秒）。回収時間は変わりません。
• 反対の結末を記録すると CHECKSUM SCAR、初回エコーサイクル達成で ECHO ORBIT を獲得します。
• アーカイブで作戦ごとの最短回収時間を確認できます。

[バトル画面]
• 目的地の操作部を左右のサイドレールへ移動し、隠れていたノードと自陣がすべて見えるようになりました。
• 折りたたみのヒンジ上に目的地ボタンが重なりません。

[操作感]
• ノードの回収時間を10秒から8秒に短縮しました。
• 回収中の進行度がノードに円弧で表示され、中間点に目印が付きます。
```

## zh-CN

```
新增回响周期，结局之后仍可继续游玩。

[回响周期]
• 达成结局后五个作战重新开启。正史记录（勋章、传输、结局）完整保留。
• 周期越高，对局时限越短（90秒→78秒→66秒→54秒）。回收时间不变。
• 记录相反结局可解锁 CHECKSUM SCAR，首次通关回响周期可解锁 ECHO ORBIT。
• 档案中可查看每个作战的最佳回收时间。

[战斗界面]
• 目的地操作区移至左右侧栏，原先被遮挡的节点与基地全部可见。
• 目的地按钮不再压在折叠屏铰链上。

[手感]
• 节点回收时间由10秒缩短为8秒。
• 回收过程中节点显示环形进度，并在中点标记刻度。
```
