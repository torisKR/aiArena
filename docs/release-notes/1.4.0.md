# Tokenfront 1.4.0 release notes

Paste each tagged block into the matching Play Console “What’s new” field. Character counts exclude the tag line and code fences; each body is under 500 characters. Billing remains disabled in this build.

## ko-KR

```text
[ko-KR]
방치 전투실이 추가되었습니다.
• 앱을 닫아도 진행도가 누적되고, 다시 열면 최대 8시간분을 정산합니다.
• 전투 단계와 크레딧을 확인하고, 크레딧으로 코어를 강화해 다음 진행 속도를 높일 수 있습니다.
• 방치 전투 저장은 기존 이야기 진행과 분리된 로컬 저장을 사용합니다.
• Android 뒤로가기를 전투 중 누르면 앱을 나가지 않고 전투를 일시정지합니다.
• 이번 빌드에서는 결제 기능이 비활성화되어 있습니다.
```

## en-US

```text
[en-US]
Idle Battle Room is now available.
• Progress continues while the app is closed, then settles up to 8 hours when you return.
• Track stages and credits, then upgrade your core to speed up future progress.
• Idle saves use separate local storage and do not replace your existing story progress.
• Pressing Android Back during a battle pauses the match instead of leaving the app.
• Purchases are disabled in this build.
```
