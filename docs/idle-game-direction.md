# AI 전쟁 시뮬레이터 — 방치형 전환 방향

상태: 사용자 승인 장르 방향 / 신규 시스템 미구현. 기존 1.3.2 시작 종료 수정 릴리스와 분리한다.

## 핵심 경험
접속하면 전투가 진행되고, 획득한 자원으로 AI 코어를 성장시켜 막혔던 구역을 돌파한다. 플레이어는 유닛을 계속 조작하는 대신 성장 순서·편성·도전 시점을 결정한다.

## 루프
- 순간: 자동 교전 관찰 → 자원 증가 확인 → 강화 선택 → 다음 전투에 효과 반영.
- 세션: 오프라인 보상 확인 → 성장 → 구역 보스 도전 → 다음 목표 제시.
- 장기: 구역 확장·코어 역할 해금·편성 실험. 기존 스토리 작전 및 에코는 별도 도전 콘텐츠로 보존.

## 세로 UI 제안
상단: 현재 구역/진행도, 주요 재화, 설정.
중앙: 실제 자동 전투와 보스 상태. 목표·보상 피드백만 표시하고 다중 팝업을 피한다.
전투 아래: 현재 막힌 이유를 설명하는 목표 카드와 보스 도전 버튼.
하단 패널: 선택한 코어의 강화 전후 수치·비용·강화 버튼.
고정 하단 탭: 전투 / 코어 / 작전 / 보관함. 상점은 판매 준비 전 숨기거나 사용 불가 이유를 명시한다.
작은 화면에서도 주요 터치 영역 48dp 이상, 배틀 영역을 패널이 덮지 않게 분리한다. 폴더블은 안전 영역과 접힘선을 고려한다.

## 시스템 경계
- 기존 WT는 꾸미기용으로 보존한다. 새 성장 재화를 기존 저장 잔액에 임의 변환하지 않는다.
- 공격·생존·지원 역할과 강화는 플레이로 획득한다. 광고 제거 구매는 능력치 보너스를 주지 않는다.
- 보상 광고는 선택형이며 기본 방치 보상 수령을 막지 않는다.
- 보스 패배 시 기존 재화/세이브를 지우지 않고 성장 화면으로 복귀한다.
- 앱 백그라운드에서 전투 엔진을 무한 실행하지 않는다. 복귀 시 경과 시간을 계산해 보상을 정산한다.

## 오프라인 정산 제안 (미구현)
마지막 검증된 정산 시각과 진행도 기반 수익률 스냅샷을 저장하고, 비음수 경과 시간과 상한을 적용한다. 같은 구간의 중복 수령은 원자적 저장으로 방지한다. 기기 시계 조작·시간대 변경·앱 중단·저장 실패를 테스트한다. 서버 없는 로컬 시계는 변조 방지를 보장할 수 없음을 명시한다. 보상 상한과 수익 곡선은 플레이테스트 전 [PLACEHOLDER]로 둔다.

## 단계별 구현
1. 자동 전투와 구역 진행 모델: 목표 달성/실패/보스 전환을 결정론적으로 테스트.
2. 성장 재화·강화·저장 마이그레이션: 기존 스토리 기록과 WT 보존.
3. 세로 전투 허브·코어 강화·다음 목표 UI.
4. 오프라인 정산 및 중복 지급/시계 변경 회귀 테스트.
5. 오디오: 강화 성공, 보스 진입, 구역 돌파, 보상 수령을 구별. 전투 소리는 제한하고 반복 피로를 낮춘다.
6. 실제 기기 성능·성장 밸런스·접근성 검증 후 스토어 설명 및 스크린샷 갱신.

## 참고 범위
사용자 지정 헌터 키우기(studio.gameberry.idlehunter), 화산파 키우기(com.dragonheart.muhyeop)의 공개 소개는 성장/방치 동기를 확인하는 자료다. UI 스크린샷 관찰은 별도 조사 중이다. 캐릭터·아트·고유 텍스트는 복제하지 않는다.

## 출시 수락 기준
실제로 앱을 켜면 자동 전투가 시작되고 강화의 결과가 다음 전투에 반영될 것. 정산 중 강제 종료에도 중복 보상이 없을 것. 기존 저장 데이터가 보존될 것. 구현되지 않은 길드/PvP/소환/상점은 표시하거나 홍보하지 않을 것. 1.3.2 시작 종료 수정의 릴리스 검증은 독립적으로 유지할 것.
